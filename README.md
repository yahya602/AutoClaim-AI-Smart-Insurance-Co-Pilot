## 🎯 Features
- **Multimodal Integration:** Processes accident images (CNN), financial data, and incident PDF reports.
- **Predictive AI Engine:** Deep Learning MobileNetV2 architecture for vehicle damage classification.
- **Explainable AI (XAI):** Confidence scores and risk factor breakdown.
- **Human-In-The-Loop (HITL):** Manager review workflow with Approval/Rejection overrides.
- **Downloadable PDF Reports:** Auto-generates official signed claims summary documents.
